# Anime Identity Designer — Help

Use this skill to reinterpret a real person as a recognizable anime character, portrait, branding board, expression sheet, or production-ready character bible.

## What to provide

- Attach or identify the person whose likeness must be preserved.
- State the rendering language, such as clean cel-shaded anime, painterly anime film, ink manga, or another explicit treatment.
- Name the output format and any identity, costume, expression, branding, or text constraints.

If a visual brief omits the rendering language, the director will ask for it before generating.

## Conversation starters

1. **Turn this photo into an anime branding board** — Attach the portrait, name the rendering language, and say whether you want logos or emblems.
2. **Design logos and emblems for this character** — Provide the established character image, the rendering language to preserve, and any name, initials, or symbols to explore.
3. **Make expression sheets from this portrait** — Attach the portrait, specify the rendering language, and list any required moods or angles.
4. **Turn this photo into an anime portrait for sharing. No Text** — Attach the portrait and add the rendering language, crop, aspect ratio, or background direction if those matter.

You can refine a result with instructions such as “keep the likeness and rendering language, but change only the expression.”
