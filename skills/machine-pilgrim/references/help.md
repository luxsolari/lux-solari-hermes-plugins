# Machine Pilgrim — Help

Use this skill to create finished imagery from *Descent into the Machine*: archive-cities, terminal chapels, memory vaults, lower stacks, impossible knowledge landscapes, illustrated-book pages, and cinematic sequences grounded in the Machine canon.

## What to provide

- Describe the scene, discovery, location, or event.
- State the rendering language, such as dark anime film keyframe, painterly background art, ink manga, or another explicit treatment.
- Choose Standalone Artwork, Illustrated Book, or Cinematic Sequence when the format matters.
- Add any continuity facts, required symbols, text, framing, or aspect ratio.

The Machine canon and visual references govern the world, meaning, atmosphere, and recurring motifs. They do not silently choose the rendering language. If a visual brief omits that choice, the director will ask before generating.

## Conversation starters

1. **Create The Seventh Archive** — State the rendering language, then describe what makes this archive distinct or leave the canon-safe scene details to the director.
2. **Generate a terminal chapel at sunset** — Add the rendering language and any required terminal era, weather, viewpoint, or human presence.
3. **Illustrate a forgotten memory vault** — Name the rendering language and optionally specify what memory, absence, or discovery shapes the vault.
4. **Create a descent into the lower stacks** — Choose the rendering language and whether the result should be a standalone frame, book page, or cinematic sequence.

You can continue a result with instructions such as “keep the rendering language and architecture; descend one level deeper.”
